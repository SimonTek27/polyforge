# Sync status

Partial tree is on GitHub via API. Full source including UI (titlebar SVG icons, ribbon, Paint mode) is in the project artifact `polyforge-full-src.tar.gz`.

```bash
tar xzf polyforge-full-src.tar.gz
cd polyforge
git add -A && git commit -m "sync: full PolyForge"
git push -u origin main
```
