# ArtCraft integration (VectorCraft + PhotoCraft)

PolyForge tracks VectorCraft and PhotoCraft as vendored upstream companions.

```bash
bash scripts/sync_artcraft.sh
bash scripts/sync_artcraft.sh --check
```

Pins: `vendor/pins.toml` · CI: `.github/workflows/artcraft-upstream-check.yml` · Bridge: `polyforge-bridge`
