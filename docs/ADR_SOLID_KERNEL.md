# ADR: Solid kernel for CadMode

**Status:** Accepted for Phase 4–5 planning
**Date:** 2026-10-17

## Decision

1. Short term: mesh-parametric features + sketcher/UX.
2. Medium term: prototype OCCT behind `cad_kernel` feature flag.
3. Long term: re-evaluate pure Rust if OCCT packaging is costly.

Do not claim B-rep parity until a kernel is integrated.
